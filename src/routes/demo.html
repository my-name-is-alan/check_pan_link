Response Notes

  • files 模式会只返回文件，并把完整路径塞进 path。
  • tree 模式会返回一个根节点，下面保留目录层级。
  • 如果链接缺少提取码或提取码错误，/api/115/share/list 和 /api/123/share/list 都会直接返回结构化错误。
  • 189 支持 /web/share?code=、/t/、h5.cloud.189.cn/share.html#/t/ 这几种链接；URL 里的 code 是分享码，不是访问码。
  • 189 filelist 会优先使用分享详情里的 shareId 列目录；只有分享详情没有返回 shareId 时，才需要补 accessCode。
  • 189 常见 reason：share_available、share_not_found、share_audit_blocked、missing_access_code、invalid_access_code。
  • 光鸭云盘使用 provider API 判断分享状态，支持提取码校验，并可通过 /api/guangya/share/list 返回 files 或 tree。
